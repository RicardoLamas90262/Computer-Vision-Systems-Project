# Design Brief - Color Tracking

## Problem Statement
[Manufacturing and sorting systems need to identify objects by color quickly and accurately. The user is somone who needs to sort or check objects based on their color.]

## Proposed Solution
[Our system uses a Raspberry Pi camera to detect and track objects based on their color. The camera captures the object, processes the image, adn identifies the selected color. This can help sort objects into the correct category and make the process faster]

## CV Technique(s) used

[The main computer vision technique used is color tracking. The system uses HSV color masking to identify a specific color. This technique fits the problem becasue objects can be seperated and tracked based on their color.]

## Sucess Criteria

[The system should correctly detectt and track the selected color in at least 8 out of 10 trials under normal lighting conditions. The detected object should remain trackable as it moves across the camera's view.]
